# exemplo-set-if

- **Origem:** sintético (criado na spec 001 para documentar o formato; não veio da POC)
- **Versão do N8N:** 1.x (nós Set v3.4 e If v2.2)

Exercita expressões em um nó Set (`{{ $json.nome }}`, comparação numérica) e o desvio do If pelas portas `true` e `false`. Os itens de saída do If mantêm todos os campos de entrada (`includeOtherFields`).
